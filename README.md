# Tutor Connect Hub

Cria uma landing page simples para o TutorIscte, uma plataforma onde estudantes universitários marcam sessões de explicações (matemática, desenvolvimento ágil, algoritmos, programação) com colegas tutores. Deve ter: hero section com título e call-to-action 'Marcar Sessão', secção de como funciona (3 passos), secção de disciplinas disponíveis, secção de FAQ, e um botão de agendamento. Design limpo e moderno, cores azul e branco.
